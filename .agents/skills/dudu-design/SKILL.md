# DuDu design workflow

1. Read `AGENTS.md`, `REQUIREMENTS.md`, `TASKS.md`, and `docs/design-spec.md` completely.
2. For design work, edit only `docs/design-spec.md` unless the active task explicitly grants a different file.
3. For review work, inspect `dist/` at mobile, tablet, and desktop widths.
4. Write actionable findings to `docs/reviews/antigravity-visual.md` with severity, viewport, evidence, and a narrow suggested fix.
5. Do not change JavaScript behavior or claim an integration exists.
